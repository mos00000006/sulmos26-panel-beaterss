# SULMOS26 Automotive V47 — Premium Blueprint-Style Vehicle Drawings

Replace these four files in your **panel-beaterss** GitHub repo (NOT retail):

- public/inspection.html
- public/inspection.css
- public/inspection.js
- public/vehicle-outline.js

Commit, wait for Panel Beater Check to pass, then run existing Panel Beater deployment workflow. Refresh the installed app. No D1 migrations or new secrets.

The main inspection now defaults to a technical front-three-quarter drawing with selectable panels. Choose Left/Right/Front/Rear/Top for orthographic views. Body types are SUV, sedan, hatchback, bakkie, van, wagon and coupe. Existing damage saving and job PDF image capture remain unchanged.

This is an *illustrative body-style drawing*, not a manufacturer's exact 2019 RAV4 or an actual freely rotatable 3D model. Only the existing 3D asset mode provides free rotation. Body-type override is available if auto-detection is wrong.
